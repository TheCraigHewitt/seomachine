# Product Features — Unifi.me

## Core Features

### Stablecoin Wallet
- Non-custodial wallet on Kaia blockchain
- Social login (LINE, Google, Apple, NAVER) — no seed phrase needed for onboarding
- Supports USDT (Tether); additional stablecoins planned (JPYC, USDC, local currency stablecoins)
- External wallet connection: Kaia Wallet, OKX, Bitget Wallet

### Earn (Interest on Deposits)
- 4–5% base APY on USDT deposits (rate varies by deposit amount)
- Flexible deposits and withdrawals — no lock-up period
- 24/7 availability
- No deposit limits, no withdrawal fees

### Payments & Commerce (Unifi Pay)
- In-app payments for games, social apps, digital content via Unifi Apps / Mini Dapps
- NFT marketplace integration
- Merchant payment solutions

### Cross-Border Transfers
- Stablecoin-to-fiat conversion via SentBe (global FX solutions)
- Off-ramp through Triple-A (Singapore DPT-licensed)
- Remittance to personal bank accounts

### Token Swap & On/Off-Ramp
- Swap tokens to KAIA or USDT within wallet
- On-ramp via partnered exchanges (BitoPro, MaiCoin in Taiwan)

### Unifi Apps Ecosystem
- Dapp Portal and Mini Dapp integration
- Gaming, social, and content services
- Missions and rewards across connected apps

## Key Differentiators
1. **LINE integration**: No separate app — 200M+ LINE users can access instantly
2. **Non-custodial + social login**: Web3 security with Web2 simplicity
3. **Stablecoin-first**: Not a general crypto wallet — focused on stable value and real utility
4. **Asian market focus**: Designed for Japan, Taiwan, Thailand, Indonesia from day one
5. **Earn + Spend in one place**: Interest on idle assets + payment utility in connected apps

## Target Markets
- Primary: Japan, Taiwan, Thailand, Indonesia
- Secondary: Global LINE user base
- User profile: Web2 users new to crypto, seeking stable earning and easy cross-border payments
